** SurakshaNetra **

SurakshaNetra is an AI-powered surveillance frontend prototype developed for ""Tekathon 5.0 – Chandigarh University’s Internal SIH Round"".

The prototype focuses on a tactical surveillance command interface with:

- 📊 Surveillance Dashboard
- 📹 Camera Monitoring
- 🚨 Alerts & Notifications
- 🎥 Unusual Clips
- 👤 Officer Profile & Settings
- 🔐 Restricted Management Panel

 Technologies

- HTML5
- CSS3
- JavaScript

Project Focus

Frontend prototype for an intelligent surveillance and monitoring system, designed around the requirements of ""SIH Problem Statement 26187"".
